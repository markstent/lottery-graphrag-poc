# Graph Visualisation Specification

## Node states
- seed
- active
- candidate
- traversed
- selected
- discarded
- ontology
- source_record

## Edge states
- candidate
- active
- traversed
- evidence_path

## Behaviour
- progressive expansion
- stable existing node positions where practical
- maximum visible nodes configurable
- cluster beyond visual threshold
- labels readable at presentation distance
- source provenance available on click
- evidence path mode simplifies to supporting route only
