# Product Requirements

## Product outcome

A presentation-quality experimental application that proves or disproves the incremental value of graph and ontology context for AI agents working over a multinational synthetic lottery enterprise.

## Primary users

1. Executive/business audience
2. Data/AI leaders
3. Architects and engineers
4. POC owner/operator

## Core capabilities

- configure a synthetic enterprise world
- inject known patterns
- ask arbitrary questions
- execute A/B/C retrieval configurations
- visually observe retrieval
- inspect evidence
- watch graph traversal
- replay runs
- run a 30-question benchmark
- compare quality, evidence, latency and token usage
- demonstrate how graph/ontology overlays existing data

## Product success

A new viewer should understand within minutes:

1. the baseline uses existing data + ordinary retrieval,
2. the enhanced approach adds graph + ontology,
3. Neo4j does not replace the data layer,
4. graph traversal finds connected context,
5. benchmark results quantify where this helps and where it does not.
