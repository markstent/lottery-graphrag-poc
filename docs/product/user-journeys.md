# User Journeys

## Journey 1 — Ask a question

1. Open Live Lab.
2. Enter an enterprise question.
3. Select A/B/C comparison.
4. Run.
5. Watch baseline retrieve chunks.
6. Watch graph system resolve/traverse entities.
7. Read answers.
8. Inspect evidence and scores.
9. Replay execution.

## Journey 2 — Plant a scenario

1. Open Scenario Lab.
2. Select a scenario.
3. Choose markets/cohorts/strength/noise.
4. Generate a new deterministic world.
5. Ask blind questions.
6. Compare retrieval against hidden truth.

## Journey 3 — Run benchmark

1. Select dataset and model.
2. Run benchmark suite.
3. Watch progress.
4. Open Results Dashboard.
5. Compare A/B/C by complexity.
6. Drill into failures.

## Journey 4 — Explain architecture

1. Open Semantic Layer screen.
2. Show existing data sources.
3. Show entity mapping.
4. Show ontology.
5. Show Neo4j overlay.
6. Show agent consuming both source facts and graph context.
