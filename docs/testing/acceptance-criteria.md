# Acceptance Criteria

## Core

- A/B/C run on same world/model.
- Truth ledger is unreachable from retrieval.
- Graph events shown in UI correspond to real backend events.
- Evidence is inspectable.
- Replay reconstructs actual event sequence.
- Benchmark results are reproducible.

## UX

- baseline and graph approaches are immediately distinguishable.
- graph never defaults to entire-database view.
- semantic-layer screen clearly shows augmentation rather than replacement.

## Quality

- lint/type/test/build gates pass.
