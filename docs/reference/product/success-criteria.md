# Success Criteria

The POC is successful if:

- all three configurations run over the same synthetic world
- benchmark results are reproducible
- viewers can visually understand graph traversal
- every graph traversal shown in the UI is backed by real telemetry
- evidence is inspectable
- graph and ontology value can be measured independently
- the semantic-layer view makes clear that graph augments rather than replaces source data
- the entire runtime can use a local open model
- the application is testable, maintainable and presentation-ready
