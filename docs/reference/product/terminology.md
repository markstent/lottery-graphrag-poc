# Terminology

**Existing data layer**: structured tables, documents, telemetry and analytical sources representing current enterprise-style data access.

**Graph overlay**: Neo4j semantic layer connecting authoritative source entities.

**Ontology**: canonical model defining what enterprise concepts mean and how they relate.

**Standard RAG**: semantic/vector retrieval over text/context without graph traversal.

**GraphRAG**: retrieval that uses graph entities and relationships to expand or guide context.

**Truth ledger**: hidden evaluator-only record of planted scenario truth.

**Evidence path**: graph path that materially supports an answer.

**Configuration A**: conventional RAG.

**Configuration B**: graph relationships added.

**Configuration C**: graph + ontology added.
