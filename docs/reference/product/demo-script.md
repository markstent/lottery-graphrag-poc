# Initial Demo Script

This is a provisional script to be refined after real benchmark results exist.

## Scene 1 — Existing data layer

Show source systems and explain that the synthetic enterprise already has structured data, documents and telemetry.

## Scene 2 — Add semantic layer

Reveal ontology and Neo4j overlay above existing sources.

## Scene 3 — Simple question

Ask a factual question where all approaches perform similarly.

Purpose: establish fairness.

## Scene 4 — Multi-hop question

Ask why digital conversion changed in one market.

Watch graph traversal connect product -> platform -> version -> incident.

## Scene 5 — Cross-market question

Ask whether a similar issue occurred elsewhere.

Show traversal reaching another market.

## Scene 6 — Pattern question

Ask for unusual account/device clusters.

Show graph topology advantage.

## Scene 7 — Benchmark

Show A/B/C results by complexity.

## Scene 8 — Conclusion

Return to architecture view:

Existing data stays.
Graph + ontology adds enterprise context.
