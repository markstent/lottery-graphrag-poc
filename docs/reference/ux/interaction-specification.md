# Interaction Specification

- Clicking an evidence citation opens Evidence Explorer.
- Clicking a graph node pins its details.
- Clicking a timeline event replays visual state to that point.
- Graph expansion occurs only from real backend events.
- Candidate nodes are muted.
- Selected evidence remains prominent.
- Rejected nodes fade but may remain inspectable.
- Baseline and graph panes start simultaneously where possible.
- Scoring appears only after both requested configurations complete.
